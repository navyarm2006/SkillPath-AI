# SkillPath AI 🚀

###  Personalized Roadmap to Job-Ready Skills

SkillPath AI is a web-based learning assistant designed to help students identify the skills they need for their chosen career and organise their learning journey.

Many students want to prepare for jobs but struggle to decide what to learn, where to start, and how to practise. SkillPath AI helps them take the first step with a structured learning roadmap.

## ✨ Features

- **Personalized Career Roadmap:** Generates a learning plan based on the selected career and existing skills.
- **7-Day Learning Plan:** Breaks learning into daily tasks.
- **Free Learning Resources:** Helps students find tutorials to develop their skills.
- **Practice Questions:** Provides multiple-choice questions with answer feedback and scoring.
- **Progress Tracking:** Allows students to track their learning tasks.

## 🎯 Target Users

- College students preparing for placements
- Beginners learning programming and technology skills
- Students who need structure in their self-learning journey

## ⚙️ How to Run the Project

### 1. Install Python

Install Python on your computer if it is not already installed.

### 2. Install Flask

Open a terminal in the project folder and run:

```bash
pip install flask
```

### 3. Run the application

```bash
python webapp.py
```

### 4. Open the website

Open your browser and visit:

http://127.0.0.1:5000/
